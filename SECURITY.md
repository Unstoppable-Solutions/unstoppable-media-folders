# Security Policy

## Supported versions

The latest released version of Unstoppable Media Folders receives security
updates. Please keep the plugin updated to the current release.

## Reporting a vulnerability

Please report security issues **privately** — do **not** open a public GitHub
issue or forum post.

Email: **support@unstoppablesolutions.app**

Please include:

- Plugin version, WordPress version, and PHP version
- A description of the issue and its potential impact
- Steps to reproduce, or a proof of concept

We will acknowledge your report, investigate, and coordinate a fix and a
responsible-disclosure timeline with you. Thank you for helping keep users
safe.
